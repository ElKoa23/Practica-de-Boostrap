# Presentación Personal - Práctica con Bootstrap

Este repositorio contiene un proyecto enfocado en el maquetado y diseño web responsivo utilizando **Bootstrap**. Consiste en una página de presentación personal estática, diseñada para poner en práctica la implementación de componentes preconstruidos del framework.

## 🚀 Características del Proyecto

* **Diseño 100% Responsivo:** La interfaz se adapta dinámicamente a dispositivos móviles, tablets y pantallas de escritorio.
* **Componentes Nativos:** Uso intensivo del sistema de grillas (Grid System), barra de navegación (Navbar), tarjetas (Cards) y botones propios del framework.
* **Sin JavaScript Personalizado:** Toda la interactividad del sitio (como menús desplegables o componentes dinámicos) funciona exclusivamente a través del archivo de JavaScript nativo que incluye Bootstrap.

## 🛠️ Tecnologías Utilizadas

* HTML5
* CSS3
* Bootstrap (v5.x)
